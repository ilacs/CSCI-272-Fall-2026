## What I learned

- A repository is a portfolio for your projects that documents, files and code. Your progress is documented and kept to view as history.

- A README file helps tell viewers the focus of your repository. Having a README is also great to remind you of the focus and importance of your project.
  
- A commit records the changes that you’ve made the your files, documents and/or code in your repository. When you make a change and are about to commit, the text entails what you changed.
