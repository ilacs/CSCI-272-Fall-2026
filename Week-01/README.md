# Week 1

This folder contains my Week 1 C++ practice work.

## What I learned

- A repository is a portfolio that documents your work. It also stores the history and changes you make to your project.
  
- A README file helps readers understand the motive of your portfolio. It is a short description that entails what your work will contain and what is expected.

- A commit records the changes you made to your project. Because a repository captures the history of your work, committing will entail the specific change you made.
